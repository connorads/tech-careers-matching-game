# TechMatch Challenge

https://connorads.github.io/tech-careers-matching-game/

**TechMatch Challenge** is an interactive web-based game designed to engage students at career fairs by helping them learn about various tech job roles through matching job titles with their descriptions.

Was made in collaboration with [ChatGPT o1-mini](https://chatgpt.com/share/67026389-42e0-8012-af0f-9d4d2ee627ba), [ChatGPT o3-mini-high with Deep Research](https://chatgpt.com/share/67c4c9f6-bd18-8012-9b97-8902c10b2117) and [Claude 3.5 Sonnet with GitHub Copilot agent mode](https://code.visualstudio.com/blogs/2025/02/24/introducing-copilot-agent-mode).
